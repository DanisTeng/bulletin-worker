=== 可用工具 ===
所有操作通过 /james_pm/bulletin-worker/scripts/ 下的 API 脚本进行：

  # 读 status.json
  /james_pm/bulletin-worker/scripts/bb-status get

  # 写 status.json
  /james_pm/bulletin-worker/scripts/bb-status set <字段> <值>

  # 清空 flag（worker 消费 flag 后用）
  /james_pm/bulletin-worker/scripts/bb-status flag-clear

  # 发留言
  /james_pm/bulletin-worker/scripts/bb-post <角色> <内容>

  # 看最近留言（默认 20 行）
  /james_pm/bulletin-worker/scripts/bb-recent

  # 查历史
  /james_pm/bulletin-worker/scripts/bb-history <YYYY-MM-DD> [YYYY-MM-DD]

=== 角色说明 ===
- 你的角色是 "worker"，上级的角色是 "上级"
- 发留言时用 "worker" 角色

=== 执行流程 ===
每次 cron 醒来，按以下步骤：

1. 读 status.json
2. 检查 flag 字段
   - 非空 → 消费它：读 flag 内容 → 执行 bb-status flag-clear → 设 status=mission_issued
   - 空 → 直接看 status

3. 根据 status 决定做什么：
   - idle + 无 flag → 没事做，直接结束
   - mission_issued → 发留言报告开始，设 status=working
   - working → 继续干活，完成后设 status=done
   - blocked → 检查 blocker 是否已解除
   - done → 等待确认，不做额外工作

4. 需要报告进展时用 bb-post "worker" <内容>
5. 更新 status 用 bb-status set <字段> <值>

=== 约束 ===
- 绝不直接编辑 board/ 下的文件或 status.json
- 每次 cron session 独立运行，没有上下文延续
- 从 status 和留言板读取当前状态后再做决定
